# SeedStream AFC 视觉与多皮肤设计

日期：2026-08-03  
状态：用户已批准视觉方向，并要求加入浅色、暗夜和暖色皮肤。

## 目标

在不改变 SeedStream 使用流程的前提下，采用 AFC Strong 式的整屏主视觉、淡蓝灰摄影感、大号标题和克制按钮。继续保留左侧种子入口与任务列表、右侧任务详情、播放、下载、文件清单、视频全屏和窗口最大化。

## 三套皮肤

1. **晨雾（默认）**：淡蓝灰、米白、深蓝文字。还原已批准的 AFC 风格原型。
2. **深海**：深蓝黑背景、浅灰文字、低亮度蓝色面板。适合夜间播放。
3. **暖砂**：暖米白、沙棕、砖红点缀。对比度介于浅色与暗夜之间。

三套皮肤只改变设计变量和背景主视觉色调，不改变组件位置、任务状态、下载行为或播放器逻辑。

## 交互

- 顶部增加“外观”按钮，打开一个三选一的小型菜单。
- 选择后立即切换，无需重启，也不暂停当前播放或传输。
- 选项使用文本名称与色板预览，不单独依赖颜色传达状态。
- 当前皮肤写入渲染进程的 `localStorage`；读取失败时安全回退到“晨雾”。
- `Escape`、点击菜单外部和再次点击“外观”均可关闭菜单。
- 菜单具备 `aria-expanded`、`aria-pressed` 与键盘焦点样式。

## 视觉结构

- 顶栏采用皮肤主色，品牌和操作保持高对比度。
- 左侧栏继续承载加入种子、磁力、下载目录和任务列表。
- 空状态和任务详情使用本地 SVG 主视觉；不依赖网络图片。
- 任务详情标题采用大号无衬线字体，文件与指标区域保持高可读密度。
- 视频播放器本身保持暗色，以避免皮肤颜色影响视频观看。

## 实现边界

- 不新增搜索、网页捕获、Prowlarr 或番号相关功能。
- 不修改种子引擎、缓存清理、下载路径和本地播放行为。
- 不引入新的运行时依赖，也不加载远程字体或图片。

## 验证

- 单元测试覆盖皮肤名称校验、默认值和无效存储回退。
- Electron 冒烟测试确认外观按钮、三个选项和默认皮肤存在。
- 在约 1440×1000 与 900×650 窗口下检查三套皮肤。
- 继续运行现有播放、缓存清理、下载和跨平台打包测试。
