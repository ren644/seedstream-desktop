# SeedStream 视频全屏与窗口最大化设计

日期：2026-08-01

## 目标

SeedStream 同时提供两个互不替代的放大入口：视频播放时可进入显示器全屏，应用窗口可最大化并再次点击还原。Mac 和 Windows 使用相同的显式按钮，系统原生窗口控制仍然保留。

## 交互设计

- 顶部工具栏新增“窗口最大化”按钮。点击后由主进程切换当前窗口的最大化状态，并把按钮文字更新为“还原窗口”；再次点击恢复原尺寸。
- 播放器标题栏新增“全屏播放”按钮。点击后优先对 `<video>` 使用标准 Fullscreen API；浏览器内核不支持时尝试兼容接口，再退回让整个播放器区域全屏。
- 双击视频执行相同的全屏切换。进入或退出全屏后监听 `fullscreenchange`，同步按钮文字和无障碍状态。
- 全屏请求失败时显示中文提示，不影响当前播放，也不关闭已下载文件。

## 安全与边界

窗口操作只通过受信任渲染页可调用的固定 IPC 通道执行，渲染进程不能传入窗口标识或任意命令。主进程只操作 SeedStream 的主窗口。视频全屏只在用户点击或双击时触发，不自动劫持屏幕。

## 验证

- 单元测试确认 IPC 名称唯一、全屏按钮状态文字正确。
- UI 冒烟检查确认窗口最大化桥接和两个按钮均存在。
- 在打包后的 Mac 应用中使用已完成的 Sintel 视频，实际验证窗口最大化、还原、视频全屏、退出全屏和继续播放。
- 完整运行测试、依赖审计、DMG/ZIP/Windows EXE 校验后发布 GitHub v0.1.3。
