# SeedStream 极简媒体台设计

## 目标

将 SeedStream 从“下载器 + 搜索中心”收敛为一个本地优先的种子媒体台：导入 `.torrent` 或磁力链接，查看任务，边下边播，永久下载，并在完成后本地播放。聚合搜索、网页捕获、搜索源/Prowlarr 和番号识别全部退出产品界面与运行时。

## 视觉方向

采用“编辑部式媒体控制台”：深墨黑底色、暖橙单一强调色、大标题、细分隔线和充足留白。界面保留媒体设备的专业感，但减少发光、网格与多层卡片。90% 的操作保持熟悉直接，只在任务切换、磁力抽屉和空状态中加入少量有辨识度的动效。

参考与吸收的原则：

- [Dennis Snellenberg](https://dennissnellenberg.com/)：大字号、简洁导航、克制的页面转场。
- [Rauno Freiberg — Novelty](https://rauno.me/craft/novelty)：高频操作应熟悉稳定，新意作为少量对比出现。
- [Rauno Freiberg — What will you ship?](https://rauno.me/craft/vercel)：固定网格、清晰字阶、性能和无障碍优先于装饰。
- [Bruno Simon](https://bruno-simon.com/)：产品只需要一个真正有记忆点的交互，不需要让每个元素都表演。

只借鉴设计方法，不复制页面、素材、品牌或源代码。

## 信息架构

窗口继续使用双栏结构：

1. 顶栏只保留品牌、窗口最大化、使用帮助和本地引擎状态。
2. 左栏顶部是统一的“加入媒体”区域，主按钮打开 `.torrent`，次按钮打开磁力链接抽屉。
3. 左栏中部展示下载目录，底部展示任务列表。
4. 右栏空状态直接提示两个入口；选中任务后展示标题、进度、节点、播放器和文件清单。
5. 磁力抽屉只有说明、输入框、取消和“解析并加入”四个核心元素，支持 Esc、焦点循环与提交状态。

## 功能边界

- 保留：`.torrent` 打开/拖入、磁力导入、任务管理、边下边播、永久下载、本地播放、系统播放器打开、播放器全屏、窗口最大化、缓存关闭后清理。
- 删除：聚合搜索、Internet Archive、Torznab、Jackett/Prowlarr、网页浏览/捕获、搜索结果令牌、番号识别和所有相关 IPC。
- 旧的 `search-providers.json` 不再读取，也不主动删除，便于降级或人工恢复。
- 已安装在电脑上的 Prowlarr 不受影响；SeedStream 只移除与它的连接。

## 技术调整

- 磁力 URI 校验从搜索合同迁移为独立的 `magnet-uri` 模块。
- 主进程与预加载桥接只暴露磁力导入，不保留任何搜索窗口能力。
- 移除只为搜索使用的 XML 解析依赖。
- 冒烟测试改为验证极简界面、磁力抽屉、安全桥接、窗口最大化和播放器全屏。
- 版本升级为 `0.2.2`，生成 macOS 与 Windows 安装包后更新 GitHub。

## 验收标准

- 应用中不再出现“搜索资源”“网页捕获”“Prowlarr/Torznab”“番号识别”。
- `.torrent` 与磁力链接都能加入同一任务列表。
- 磁力抽屉键盘可用，错误信息明确，提交成功后自动关闭并选中新任务。
- 800×600 到常规桌面尺寸无横向溢出；降低动态效果设置生效。
- 单元测试、界面冒烟测试和打包检查通过。
