# SeedStream v0.3.2

发布日期：2026-08-05

## 这一版的变化

- 修复磁力链接解析时整个弹窗被锁住、关闭和取消无法使用的问题。
- 新增真正可中断的磁力解析；取消后会终止临时任务并清理元数据缓存。
- 给临时任务移除与缓存清理增加硬超时，避免底层回调异常时无限等待。
- 解析弹窗显示 DHT / Tracker 节点发现状态和 60 秒剩余时间；按钮、右上角关闭和 Esc 均可取消。
- 保留磁力链接自带 Tracker，并补充 OpenTrackr 与 WebTorrent Tracker 作为元数据发现备用入口。

## 验证

- 50+ 项单元与集成测试通过，覆盖取消竞态、超时和缺失移除回调。
- 使用两个本机回环 WebTorrent 节点交换真实磁力元数据，成功取得合法测试视频的文件清单，全程不接入公网。
- 在 macOS Electron 界面实际完成“粘贴磁力 → 等待状态 → 取消解析 → 弹窗关闭”流程。
