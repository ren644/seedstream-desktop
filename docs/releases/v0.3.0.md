# SeedStream v0.3.0

发布日期：2026-08-03

## 这一版的变化

- 主界面更新为开阔、克制的画面式媒体工作台，同时保留左侧任务、右侧详情的原有操作路径。
- 新增本地原创的山谷主题画面，不加载远程图片或网页资源。
- 新增三套可切换皮肤：晨雾、深海、暖砂。
- 皮肤选择保存在本机，重启后自动恢复；切换过程不会中断下载或播放。
- 外观菜单支持键盘焦点、Esc 关闭和点击外部关闭。
- 优化 900px 窄窗口、任务详情、播放器、进度数据和文件清单布局。
- 更新 macOS / Windows 离线使用指南和首次打开说明。

## 验证

- 48 项单元与集成测试全部通过。
- Electron 界面冒烟测试通过，确认三套主题入口、默认主题与安全渲染桥接。
- 完成 1440×1000 的三主题离屏渲染检查和 900×650 紧凑窗口检查。
- 完成任务详情、播放器、文件清单在浅色与暗夜界面的视觉检查。
- 播放缓存清理、永久下载、本地播放、视频全屏和窗口最大化逻辑保持原有测试覆盖。
