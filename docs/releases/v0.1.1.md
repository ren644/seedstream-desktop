# SeedStream v0.1.1

本版本修复播放器在零节点任务上长时间显示“正在缓冲”的问题。

## 修复与改进

- 约 12 秒仍未发现节点时，明确显示“没有可用节点”，不再假装正在边下边播
- 播放器不再等待可能长期未决的浏览器播放 Promise，关闭、重连等按钮不会被缓冲过程锁死
- 已连接节点但长时间没有新数据时显示独立停滞诊断
- 播放器新增“重新连接”，会清理当前临时缓存并重新执行原种子的节点发现
- MKV、AC3、DTS/TrueHD、H.265/HEVC 等文件名信号会提前显示兼容性提醒
- 关闭播放后清除旧的无节点状态，避免下次播放继承错误提示
- 保持私有种子约束，不擅自注入公共 Tracker

## 安装包

- `SeedStream-0.1.1-mac-arm64.dmg`：Apple Silicon Mac 推荐
- `SeedStream-0.1.1-mac-arm64.zip`：macOS 备用包
- `SeedStream-0.1.1-windows-x64-setup.exe`：Windows x64 一键安装版
- `SeedStream-0.1.1-windows-x64-portable.exe`：Windows x64 便携直开版

安装包仍未使用商业代码签名。首次运行请先确认来源并核对 `SHA256SUMS.txt`，再按离线指南中的系统认可方式打开。
