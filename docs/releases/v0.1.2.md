# SeedStream v0.1.2

本版本补齐“下载完成后继续观看”的播放器闭环。

## 新功能与修复

- 下载完成后，任务顶部新增“播放视频”快捷入口
- 新增“系统打开”，可把不兼容编码交给 VLC、IINA 或系统默认播放器
- 视频文件清单新增“本地播放”，直接读取永久下载目录
- 应用退出重开后，已完成任务仍可在没有节点、没有网络时播放
- 本地播放支持 HTTP Range，可拖动视频进度
- 本地播放不重新连接 Torrent，也不会建立或删除临时播放缓存
- 文件被移动、删除或大小变化时显示明确提示
- 修正任务仍有节点和下载速度时误显示“等待可用节点”的状态文字
- 本地媒体服务仅监听回环地址，并使用随机令牌、路径限制和符号链接防护
- 移除 WebTorrent 间接依赖中未使用且存在已知 SSRF 风险的 `ip` 包

## 安装包

- `SeedStream-0.1.2-mac-arm64.dmg`：Apple Silicon Mac 推荐
- `SeedStream-0.1.2-mac-arm64.zip`：macOS 备用包
- `SeedStream-0.1.2-windows-x64-setup.exe`：Windows x64 一键安装版
- `SeedStream-0.1.2-windows-x64-portable.exe`：Windows x64 便携直开版

安装包未使用商业代码签名。首次运行请确认来源并核对 `SHA256SUMS.txt`，再按随包使用指南中的系统认可方式打开。
