# SeedStream v0.2.1

本版本在资源搜索中心加入可选的“番号识别”模式，重点改善编号写法不一致导致的漏搜和无关结果排序，同时保持现有搜索源与安全边界不变。

## 新功能

- 聚合搜索新增“番号识别”开关，默认关闭，不影响普通关键词搜索
- 自动规范化大小写、全角字符、空格、下划线和连字符
- 支持 `SSIS-123`、`SSIS123`、`HEYZO 1234`、`259LUXU-1234`、`FC2-PPV-1234567` 等常见结构
- 实时显示识别后的标准番号；无法识别时明确提示，不会退回到宽泛关键词搜索
- 每个搜索源最多查询三种等价写法，控制请求数量
- 标题中完整包含番号的结果显示“番号精确”，并在推荐顺序中优先于无关的高节点结果
- 完整匹配带有边界校验，例如 `SSIS-1234` 不会误判为 `SSIS-123`

## 搜索范围

识别模式只在本机处理输入和排序，不内置新的搜索站点。可见结果仍取决于 Internet Archive 和用户自行启用的 Torznab 来源。

## 安装包

- `SeedStream-0.2.1-mac-arm64.dmg`：Apple Silicon Mac 推荐
- `SeedStream-0.2.1-mac-arm64.zip`：macOS 备用包
- `SeedStream-0.2.1-windows-x64-setup.exe`：Windows x64 一键安装版
- `SeedStream-0.2.1-windows-x64-portable.exe`：Windows x64 便携直开版

安装包尚未使用商业代码签名。首次运行请确认来源并核对 `SHA256SUMS.txt`，再按随包使用指南中的系统认可方式打开。
