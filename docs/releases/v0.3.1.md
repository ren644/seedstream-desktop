# SeedStream v0.3.1

发布日期：2026-08-04

## 这一版的变化

- 启用全新的“视频框负形”品牌标志：两个错位媒体窗口由一条 S 形数据流连接。
- 标志采用深海蓝、暖珊瑚与暖白三种纯色，不使用渐变、阴影或立体效果。
- 同步更新软件标题栏、macOS `.icns` 与 Windows `.ico` 图标。
- 保持三套界面皮肤、下载、边下边播、本地播放和缓存清理功能不变。

## 验证

- 单元、集成与 Electron 界面冒烟测试通过。
- 验证 SVG 只包含固定纯色，没有渐变和滤镜。
- 验证 macOS 与 Windows 安装包均使用新图标资源。
