# SeedStream v0.1.3

本版本补齐视频全屏和软件窗口最大化的两套独立控制。

## 新功能与修复

- 播放器右上角新增“全屏播放 / 退出全屏”按钮
- 支持双击视频进入或退出全屏，按 Esc 也可退出
- 使用桌面应用原生全屏并只显示播放器，规避 macOS 网页全屏卡住的问题
- 主进程捕获 Esc 并即时同步退出状态，避免全屏后无法返回
- 应用顶部新增“窗口最大化 / 还原窗口”按钮
- 窗口最大化状态与按钮文字自动同步
- 全屏与窗口最大化互相独立，可以按观看需要分别使用
- 补充首次打开说明、离线指南、异常提示与自动化回归测试

## 安装包

- `SeedStream-0.1.3-mac-arm64.dmg`：Apple Silicon Mac 推荐
- `SeedStream-0.1.3-mac-arm64.zip`：macOS 备用包
- `SeedStream-0.1.3-windows-x64-setup.exe`：Windows x64 一键安装版
- `SeedStream-0.1.3-windows-x64-portable.exe`：Windows x64 便携直开版

安装包未使用商业代码签名。首次运行请确认来源并核对 `SHA256SUMS.txt`，再按随包使用指南中的系统认可方式打开。
