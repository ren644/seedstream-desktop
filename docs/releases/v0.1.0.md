# SeedStream v0.1.0

首个公开版本。SeedStream 是面向 macOS 与 Windows 的本地桌面 `.torrent` 视频播放器和下载器。

## 主要功能

- 打开、拖放或通过系统文件关联导入 `.torrent`
- 在应用内选择视频边下边播，支持 HTTP Range 拖动进度
- 永久下载、暂停、继续、任务恢复和完成通知
- 关闭播放器或退出应用后自动清理临时视频缓存
- macOS 与 Windows 平台专属首次启动引导
- 安装包附带离线使用指南和安全提示

## 下载选择

- `SeedStream-0.1.0-mac-arm64.dmg`：Apple Silicon Mac 推荐
- `SeedStream-0.1.0-mac-arm64.zip`：macOS 备用包
- `SeedStream-0.1.0-windows-x64-setup.exe`：Windows x64 一键安装版
- `SeedStream-0.1.0-windows-x64-portable.exe`：Windows x64 便携直开版

请同时下载 `SHA256SUMS.txt` 核对文件完整性。当前构建未进行 Apple 公证或 Windows 代码签名，首次启动可能出现 Gatekeeper 或 SmartScreen 提示；请阅读随附指南，不要关闭操作系统安全功能。
