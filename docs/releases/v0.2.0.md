# SeedStream v0.2.0

本版本把 SeedStream 扩展为种子播放器、下载器与本机资源搜索入口，同时保留明确的安全隔离和用户确认步骤。

## 新功能

- 顶部新增“资源搜索中心”，集中提供聚合搜索、网页捕获、磁力链接和搜索源设置
- 内置 Internet Archive 公共来源，无需密钥即可搜索
- 支持 Jackett、Prowlarr 与其他兼容 Torznab 的用户自有搜索服务
- 多来源结果自动去重、合并与排序，并显示来源健康状态、容量、节点、日期和可用性提示
- 支持直接粘贴 magnet 链接并取得种子元数据
- 支持从搜索结果或隔离网页窗口接管远程 `.torrent`
- 网页捕获使用独立 sandbox 窗口，阻止本机文件访问和危险协议，可一键清理缓存、Cookie 与登录状态
- API 密钥不进入渲染页面；系统安全存储可用时加密保存在本机
- 搜索请求增加超时、响应大小、内容类型和一次性导入令牌保护
- 修复极低传输速率可能显示为 `undefined/s` 的边界问题

## 原有能力

- `.torrent` 打开、拖放和系统文件关联
- 边下边播、永久下载、暂停、继续与断点校验
- 下载完成后内置播放器本地观看，或交给系统播放器
- 视频全屏、双击全屏、Esc 退出，以及独立的软件窗口最大化
- 纯播放缓存关闭后自动清理

## 安装包

- `SeedStream-0.2.0-mac-arm64.dmg`：Apple Silicon Mac 推荐
- `SeedStream-0.2.0-mac-arm64.zip`：macOS 备用包
- `SeedStream-0.2.0-windows-x64-setup.exe`：Windows x64 一键安装版
- `SeedStream-0.2.0-windows-x64-portable.exe`：Windows x64 便携直开版

安装包尚未使用商业代码签名。首次运行请确认来源并核对 `SHA256SUMS.txt`，再按随包使用指南中的系统认可方式打开。请只搜索、下载或分享你有权访问的内容。
