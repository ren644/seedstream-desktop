# SeedStream v0.2.2

发布日期：2026-08-03

## 这一版的变化

- 移除聚合搜索、网页捕获、搜索源/Prowlarr 和番号识别。
- 删除相关网络服务、远程网页窗口、配置桥接和第三方 XML 解析依赖。
- 保留磁力链接，改成左侧独立的“粘贴磁力”入口和极简抽屉。
- 重新设计主界面：编辑部式深色媒体台、更清晰的双栏层级、单一暖橙强调色和更克制的动效。
- `.torrent` 和磁力链接统一进入任务列表，后续播放与下载流程不变。
- 安装包明确携带跨平台 uTP 可选网络模块，保留 TCP 回退并扩大可连接节点范围。
- 旧的搜索源配置不会主动删除，但新版本不再读取。
- 更新 macOS / Windows 离线使用指南和首次打开说明。

## 验证

- 44 项单元与集成测试通过。
- Electron 界面冒烟测试通过。
- Mac 安装包实际启动通过；Windows x64 原生模块架构与安装包校验和通过。
- 在 macOS 上实际检查常规窗口、磁力抽屉和约 800×600 紧凑窗口布局。
- 播放缓存清理、永久下载、本地播放、视频全屏和窗口最大化逻辑保持原有测试覆盖。
