01 / QUICK START

三步就能开始

STEP 01

加入种子

打开或拖入 `.torrent`；也可以点击“粘贴磁力”，输入完整 magnet 链接。导入只会先建立任务清单。

STEP 02

选择视频播放

解析完成后，在视频文件右侧点击“播放”。有可用节点时会自动边缓冲边播放。点击播放器右上角“全屏播放”或双击视频即可全屏。

STEP 03

需要保留再下载

点击“下载全部”保存到永久目录；下载完成后可继续点击“播放视频”，直接在应用内本地观看。顶部“外观”可在晨雾、深海、暖砂间切换并自动记住。

02 / ADD MEDIA

只保留两种直接导入

.torrent 文件

点击左侧“打开 `.torrent`”，或把本机种子文件拖入“加入种子”区域。SeedStream 会解析文件清单，再由你选择播放或下载。

磁力链接

点击“粘贴磁力”，输入完整的 magnet:? 链接。SeedStream 会寻找节点并取得文件清单；元数据速度取决于当前做种情况。

两种导入都不会自动开始永久下载。请只访问、下载或分享你拥有权利或获得明确授权的内容。

03 / FIRST LAUNCH

安装与系统拦截

macOS · Apple Silicon

DMG 推荐
  1. 打开 DMG，把 SeedStream 拖到 Applications / 应用程序。
  2. 第一次启动时，在“应用程序”里右键 SeedStream，选择“打开”。
  3. 若仍被拦截：打开“系统设置 → 隐私与安全”，在安全区域选择“仍要打开”，再按系统提示确认。
  4. 成功打开一次后，以后可以像普通应用一样从 Dock 或“应用程序”启动。

不要运行关闭 Gatekeeper 的命令，也不要移除整台电脑的安全策略。本构建未做 Apple 公证，所以无法完全消除首次提示。

Windows · x64

Setup / Portable
  1. 安装版：双击 setup.exe，确认一次 UAC 后会自动安装、建立快捷方式并启动。
  2. 便携版：双击 portable.exe 即可，不安装、不注册 `.torrent` 文件关联。
  3. 若 SmartScreen 提示未知发布者，先确认文件来源及 SHA-256，再点“更多信息 → 仍要运行”。
  4. 若防火墙询问网络访问，只在你信任的专用网络允许；拒绝也不会影响应用打开，但可能减少可连接节点。

不要关闭 Defender 或杀毒软件。当前构建未使用 Windows 代码签名证书，因此 SmartScreen 可能显示未知发布者。

安全确认原则：只从你信任的来源获取安装包，并用同目录的 SHA256SUMS.txt 核对完整性。文件名或校验值不一致时不要继续运行。

macOS DMG

05 / CACHE & DOWNLOADS

“在线播放”仍会临时下载

在线播放

播放器会按观看位置取得种子分片，并写入应用专用临时缓存。关闭播放器、关闭 Windows 窗口退出，或退出 macOS 应用时会清理；异常退出留下的缓存会在下次启动清除。

永久下载

点击“下载全部”后，文件进入显示的下载目录，可以暂停和继续。下载完成后可直接使用内置播放器本地观看；此时不再依赖节点。遇到不兼容编码可点“系统打开”。移除任务记录不会删除已经永久下载的文件。

画面大小：播放器的“全屏播放”或双击视频只让视频占满屏幕；应用顶部的“窗口最大化”用于放大整个软件窗口，再点“还原窗口”恢复。按 Esc 可以退出视频全屏。

界面外观：顶部“外观”提供晨雾、深海、暖砂三套皮肤；切换只改变颜色与氛围，不会中断播放或下载，下次启动会继续使用上次选择。

BitTorrent 在下载时也可能上传已经取得的分片。请只下载或分享你有权获取的内容。

06 / TROUBLESHOOTING

常见状况

显示“没有可用节点”
应用等待约 10–12 秒仍未找到数据来源。可以点击播放器中的“重新连接”，检查防火墙或稍后再试；如果节点仍为 0，只能更换一个有做种者的合法来源。SeedStream 不能凭空生成不存在的内容。
能下载但视频不能播放
内置播放器受 Chromium 编解码器限制。H.265、DTS、AC3 和部分 MKV/AVI 组合可能不兼容；下载完成后点击“系统打开”，可交给 VLC、IINA 等播放器处理。
视频或软件窗口怎么放大
看视频时点击播放器右上角“全屏播放”，也可以双击视频；按 Esc、再次双击或点击“退出全屏”返回。要放大整个软件，请点击应用顶部“窗口最大化”，再点一次即可还原。
拖入文件没有反应
拖放区域只接收扩展名为 `.torrent` 的本机文件。磁力链接请点击左侧“粘贴磁力”后输入。
下载速度为什么很慢
实际速度由做种者数量、对方上传、网络连通性、防火墙和运营商限制共同决定。SeedStream 会连接该种子声明的 Tracker、DHT 和局域网节点，但不能制造不存在的高速节点。
下载占用磁盘太多
先检查左侧显示的永久下载目录。关闭播放器只会清临时缓存，不会删除永久下载；永久文件需要你在 Finder 或资源管理器中自行管理。
关闭 macOS 窗口后应用还在
这是 macOS 的标准行为。播放器会关闭并清理临时缓存；要完全退出请按 ⌘Q，或从菜单选择“退出 SeedStream”。
Windows 双击 `.torrent` 没打开
文件关联只由安装版注册。便携版用户请先打开 SeedStream，再把 `.torrent` 拖进去。
